# Viewer Antigravity 2.0 Studio Skill

Этот навык обеспечивает быстрый запуск и управление локальной студией препросмотра.

## Быстрый запуск сервера

Студия настроена на порт **3100** (так как порты 2942–3041 зарезервированы системным пулом Windows):

```bash
# Режим разработки с HMR:
npm run dev

# Либо быстрый production-сервер:
npm run start
```

## Ключевые адреса

- **Главный воркспейс со студией:** `http://localhost:3100`
- **Интерактивное демо мобильного приложения:** `http://localhost:3100/demo`
- **Локальный API-мост синхронизации:** `http://localhost:3100/api/antigravity-bridge`

## Возможности для агента

1. **Чтение пакетной очереди правок:**
   Контекстный файл задачи сохраняется в `$TMP/.antigravity-viewer-context.json` и `$TMP/ANTIGRAVITY_TASKS.md`.
2. **Получение точных селекторов и диффов стилей:**
   Каждый элемент очереди содержит селектор, путь к файлу компонента (`components/...`), номер строки и сгенерированные Tailwind-классы.
