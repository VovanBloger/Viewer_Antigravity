# Запуск Viewer Antigravity 2.0

Запустить сервер студии препросмотра:

1. Проверить доступность `http://localhost:3100`.
2. Если недоступен, выполнить `npx next start -p 3100` (в фоновом режиме).
3. Предоставить ссылку `http://localhost:3100`.
